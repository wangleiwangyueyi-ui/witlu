## 性能与自动画质

1. 普通网址先看一遍地图；再打开 `?debug=1`，关闭 vConsole 面板，展开玻璃控制台的「真机性能采样」。
2. 在「特效开关」中确认自动画质开启；从「高」开始。点击「运行 30 秒测试」，保持前台，系统会实际平移、缩放。导出或复制 JSON。
3. 记录下表。JSON 包含全部 rAF 长帧、P95、档位变化、draw call 和 JS heap；JS heap 不包含 GPU / 浏览器原生内存，不能直接用它宣称总内存 ≤350MB。
4. 连续做 3 轮；再运行秦灭六国 / 靖康 / 崖山，观察卡顿时连续 >22ms 达到 2 秒是否降一档。只有连续 <12ms 达 10 秒才会尝试升档；60Hz 设备未达到这个条件时不升档是正常的。
5. 手动关闭自动调节并选「高」，复测是否稳定 ≥50fps。自动降到省电取得的成绩应单独标记，不能冒充高档成绩。
6. 可通过 Android 开发者选项、远程 DevTools / Perfetto 或 iOS Instruments 检查实际进程内存。记录工具、口径和峰值，若没有工具则填「未测」。
