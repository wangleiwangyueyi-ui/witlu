## 性能与自动画质

1. 打开 `?year=230&debug=1`，关闭 vConsole 浮层，从验收控制台展开「真机性能采样」。在「特效开关」中确认自动画质开启，从「高」开始运行 30 秒，保持页面前台。
2. 导出或复制 JSON，保留完整 rAF 样本、P95、档位、draw call 和 JS heap。重复三轮。连续超过 22ms 达 2 秒应降一档，连续低于 12ms 达 10 秒才尝试升档。60Hz 设备可能长期达不到升档条件。
3. 关闭自动调节并固定高档再做三轮，以最低轮检验 ≥50 FPS。分别记录固定高档和自动档成绩。
4. 测量 4G 冷启动的静态图、首次可操作时间和疆域着色完成时间。若测全进程内存，请填 Android DevTools、Perfetto 或 iOS Instruments 等工具及口径。JS heap 不包含 GPU 和浏览器原生内存。
5. 记录真机结果与证据路径，未操作的项目保留「未测」。
