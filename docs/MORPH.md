# P4 疆域渲染与生长

入口是 `/lab/morph`，主地图按 `core/time` 的连续年份索引订阅时间轴。`?debug=1` 提供独立特效开关、填色透明度和十组预览。所有环境访问经 `PlatformAdapter`，距离计算在纯 TypeScript `core/edt`、`core/morph`，Worker 由 web 适配器创建。

## 数据与纹理

`pnpm data` 在完整几何之后生成 `public/data/territories/*.geojson`，只提取政权要素供运行时加载；完整行政区、CHGIS、现代省界和 parity 输入不变，派生文件继续被 Git 忽略。政权 ID 来自全局注册表的排序 key，包含同名不同时代的区分。

每对快照在 Web Mercator 东亚范围内三角剖分，外环、孔洞、MultiPolygon 均参与 GPU 光栅化。邻国先画，中国政权后画，ID 的低/高字节存于 RG。ID 渲染目标：桌面 4096²，触控设备或窄视口 2048²，Nearest、无 MSAA、无颜色空间变换、无深度和混合。原始矢量不修改。

地形片元保留浮雕的线性亮度，以政权色归一化亮度后混合；默认不透明度 40%，可调。都护府用所属颜色与斜纹，邻国和仅描边政权无填充。未覆盖陆地降低 15% 亮度。静止端点直接采样完整 ID；中间状态未改变像素仍采样原 ID，不在整个地图上切换精度。

## 距离场与缓存

GPU 将 ID 降采样为桌面 1024²、手机 512² 分类标签，再一次性异步读回。该精度专用于生长场；静态 ID 仍满足 4096²／2048²。Worker 查找变化像素及其涉及的全部政权，分别求 A、B 的有符号欧氏距离。FH 两次一维下包络变换为线性复杂度；像素中心到异类像素中心的距离减半像素，内部为负。

新出现政权在 A 侧使用都城点距离，消失政权在 B 侧使用都城点距离。上游未提供都城的政权使用该端区域像素质心，明确记录 `seedSources` 中的 `centroid`；不编造历史都城。A、B 双场作为 RG16F 纹理数组上传。Worker 返回数据通过 Transferable 移交，缓存保留自己的数组副本。LRU 上限 96 MiB，过大单项不入缓存；主线程仅保留有限几何和标签。空闲时预计算下一相邻快照，不替换可见画面。

快照对按 key 规范排序，反向播放共享同一组半精度场。`argmin(mix(sA,sB,t))` 决定唯一归属，相同分数使用稳定 ID 顺序。A、B 都有中国政权的像素排除背景候选，避免插值产生新裂缝。只在变化包围矩形内执行逐帧合成，其他像素沿用初始化结果。RT 的 scissor 使用物理纹素坐标，不乘设备 DPR。

## 效果和时间

- 金色前沿来自第一、第二候选距离差，只有变化处短时高亮。
- 开国水墨以都城种子与径向扰动调制填色；消亡光尘在 Worker 计算前沿交点，在 GPU 按进度求位置和生命期。两者随同一进度确定性反放。
- 边界采用屏幕空间三角条，彩色 1.5px 线、细白色内芯、8px 柔光包络。每 8km 加密并采样可见地形高度；端点区域淡入，中间淡出。
- 生长结束后旧边界为朱砂虚线，3 秒淡出；继续拖入中间态即隐藏残影。
- `prepare(A,B)` 保持旧画面直到新场就绪，过时请求不会覆盖最新选择。`setProgress(t)` 可停留和倒拖；快拖切换 120ms 交叉淡化。`play(A,B,duration)`、`playPrepared(reverse)`、`animateTo(t)` 按 900–1400ms 补间。
- 极致／高／省电分别最多 1800／900／180 粒子；省电取消边界柔光。ID 和 SDF 精度按设备固定，避免自动画质变化时重建场造成跳变。
- `prefers-reduced-motion` 或关闭生长时使用 120ms 交叉淡化，关闭金光、水墨、粒子、残影。每个效果还有独立开关。

## 验证和限制

`pnpm test:morph` 独立、单 worker 录制十对快照的三视口表现。审计每组 t=0、.25、.5、.75、1 的 GPU 所属 ID，与 CPU oracle 逐像素比对；同一中间时刻反转 A/B 后比较哈希；检查新增缝隙和非法 ID。性能段不执行截图或像素读回，保留所有 rAF 间隔与真实环境动画、预计算。

`Morph.audit()` 是显式调试读取，正常动画不会读回 GPU。浏览器测试另覆盖快速拖动、缓存、减少动态和 WebGL 上下文恢复。详见 [P4 验收报告](progress/P4.md)。

距离场形状是历史示意插值，不能推断每一年真实战线。1024／512 场限制极细边界和小岛的过渡精度，端点仍为完整 ID。B12 穿云、地名避让、动态朝代文字等后续阶段内容不属于 P4。WebGL2 要求沿用 P2；手机测试为桌面 GPU 的设备模拟。
