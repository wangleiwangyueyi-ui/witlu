## 三、二维地图方案

**推荐：保留现有 Three.js 引擎，改为正交俯视的 2D 模式**（而不是推倒重写）。
- 理由：疆域生长动画、海面微光、云影、标记系统、深链、测试都能保留；去掉地形位移、倾斜和旋转后，**首屏和帧率问题会大幅改善**。
- 相机：正交投影、固定正北、禁止俯仰/旋转；只允许平移 + 缩放（滚轮/双指），加缩放上下限和“复位视图”。
- 底图：保留晕渲（hillshade）作为**淡淡的纹理**而不是位移；陆地用暗蓝灰、海洋更深的夜蓝，江河用细亮蓝线，现代省界虚线（默认淡）。
- 疆域：半透明填充（约 35–45% 不透明度）+ 1.5px 清晰描边 + 边界内侧柔光；**政权色独立一套色板**，不与界面金色重复（见第六节）。
- 标签层级：政权名（衬线大字、居中、带细描边）> 都城（双圈红点 + 中字）> 州郡（虚线 + 斜体小字）> 普通城市（小白点 + 小字）> 周边民族（淡色）。**城市不再使用玻璃胶囊。**
- 周边政权（鲜卑、高句丽等）淡色/虚线描边，和参考站一致。
- 3D 代码不删除，保留为 `?terrain=1` 的实验入口，默认关闭；PLAN 中的“只有 3D”改为“默认 2D”。

## 四、并行编年（我们相对参考站的核心优势）

参考站只能显示“某一年的单个事件”。我们要把**同时存在的几个政权**讲清楚：

1. **右栏「此刻天下」**：每个并存政权一张紧凑卡（左侧色条），显示：政权名、君主·年号、都城、**该政权当年或最近一件事**。点击 → 地图聚焦该政权、其余变暗；再点取消。
2. **右栏「本朝大事」**：仿参考站的年份卡列表，但每张卡左侧用**政权色点**标明是哪国的事；当前年高亮；点击跳年。可按政权筛选（顶部色块 chips）。
3. **底部并行泳道**：在朝代总览条下方，显示当前时间窗内每个政权一条**细泳道**（政权色、带名字），泳道上的小刻度就是该国事件；立国/灭亡处有端点。**取代现在的辫状交织线。**
4. **地图事件小卡**：当前年的事件在发生地弹出小卡（年份 · 年号 · 地点 chips · ×），多个事件时按政权色区分，最多同时 2 张，其余在右栏。

## 六、视觉规范修订

- **界面色**：夜蓝底 + 金色仅用于品牌、当前年、焦点态；不再用于政权填充。
- **政权色板**：8–10 个同明度、中饱和度的色（如：靛青、赭石、松绿、绛紫、胭红、秋香、黛蓝、藕荷……），按同时存在的政权数量分配，相邻政权保证可区分；色盲模拟检查。
- **字号**：正文 ≥14px，次要信息 ≥12px，禁止 10px 以下；白字对比度维持 ≥7:1。
- **玻璃**：只用于顶栏、右栏、底栏、弹出卡；地图上的标签不用玻璃。
- **动效**：天气/粒子默认降为“轻”，只在重大事件（如靖康、崖山）出现；不得遮挡疆域。
- **图例卡**（地图左下）：时期阶段 + 阶段圆点 + 政权色块（悬停高亮/点击聚焦）+ 符号说明 + 一行免责声明。

## 七、开场动画重做（≤6 秒，可跳过）

1. 0–1.5s：星空背景（细微星点、缓慢旋转），地球从暗处浮现。
2. 地球：**NASA Blue Marble 白天贴图**（公有领域）+ 夜晚城市灯光贴图在晨昏线背面淡入 + 法线/高光（海面反光）+ **大气层蓝色菲涅尔光晕** + 半透明真实云层贴图慢速漂移。
3. 1.5–4s：镜头从太平洋上空转向东亚，逐渐推近，中国区域出现一圈金色描边微光。
4. 4–5.5s：穿过云层（云贴图放大淡出）→ 交叉淡入到 2D 地图的同一视野，无黑屏、无跳变。
5. 书法「两千四百年 · 一图观之」按笔顺写出，与镜头推近同步，结束时缩到顶栏 Logo 位置。
6. 省电 / reduced-motion：静止地球 + 标题淡入 1.5 秒。手机贴图用 2K，桌面 4K，懒加载不阻塞地图。

## 八、其他需要一起处理的细节

- 搜索框放进顶栏，支持人物/地名/年号/多人同看（功能已存在，只改位置）。
- “开始导览”改成顶栏 ⋯ 菜单里的“导览”，首次访问用一条可关闭的小提示条（仿参考站“初来乍到”）。
- 地点卡（点城市）从右栏位置滑出覆盖右栏，而不是再叠一个面板。
- 删除地图上与右栏重复的信息；任何信息在一屏内只出现一次。
- 地图可读性：标签碰撞避让、缩小时隐藏小城市；政权名长时自动换行或使用简称（“燕（公孙氏）”）。
- 加载：先出 2D 静态底图 + 疆域（目标 ≤2 秒），再加载装饰层。
- 性能目标（2D 后重新设定）：桌面 ≥55fps，手机 ≥50fps，首屏可交互 ≤3s（4G 模拟）。
