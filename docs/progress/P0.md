## 性能

- 本机生成耗时 20.47 秒；进程最高 RSS 845.9 MiB。
- Vite 首屏 JS + CSS：gzip 70.78 KiB（P0 尚未加载地图渲染器）。静态数据共 242 文件、51.86 MiB；最大单个文件 coexistence.json，2.07 MiB。
- 本机开发页壳导航耗时 840.8 ms，90 帧 rAF 采样中位帧间隔 16.70 ms（约 59.9 fps），P95 16.80 ms。原始结果见 browser-metrics.json。这是静态页壳采样，不代表后续 Three.js 渲染性能；地图帧率、显存与真机预算在 P2 开始实测。

## 与 PLAN 的差异及原因

- PLAN 第 3 节的 164 快照为旧计数，固定上游已有 198；采用实际全量计数，未降低阈值。
- 上游默认 export_geojson 截断于 1948，本导入不截断；s_prc 原本为空，保持其空几何并单独导出现代省界。现代阶段的面积、都城、配色与事件点面归属通过该独立图层关联，不手改或补画边界。
- 自动归属遇到源几何外、海上或海外事件时不伪造政权，使用 null + 待归属 lane。未提供迁都时间的档案都城只标 candidate；原始资料不足不使用文字锚点代替都城。
- 快速拖动阈值暂定 300 年 / 秒（可传入 speed），PLAN 未指定数值；P4 / P5 根据交互实测再调整。
