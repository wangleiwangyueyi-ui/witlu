## 范围、偏差与已知限制

本阶段所列功能和本地验收已完成。待外部环境确认的事项是微信真机保存菜单、实际 WebMCP 客户端接入和线上部署；这些尚未执行，不以模拟器或本地预览代替。

- 首次开场只用于无参数首页；深链和嵌入直接打开目标内容。`terrain=0` 原样接受，但遵循仓库“只有 3D”的要求，不切换 2D。
- atlasAPI 使用 Promise，以支持异步静态数据；保留上游方法名和主要查询字段，并增加分组路线与来源提示。MCP 继续使用固定上游查询实现，避免复制历史边界判断。
- WebMCP 是实验性接口；e2e 模拟注册和调用，实际外部代理接入尚未真机验收。普通 atlasAPI 不依赖 WebMCP。
- 微信采用图片长按保存；已做移动视口模拟，尚未在真实微信客户端检查其系统菜单。没有接入微信分享 SDK 或后端。
- 离线缓存不是完整离线地图包：100 个运行时资源，每项不超过 2 MB；未访问或已淘汰的地形、音频和朝代数据仍需联网。
- SEO 分数来自本地生产预览，不代表 witlu.com 已上线；本阶段不推送、部署或修改 DNS。
- Vite 仍提示主应用与 Three.js 引擎压缩前 bundle 超过 500 kB（约 548 kB / 622 kB，gzip 约 186 kB / 164 kB）；未提高警告阈值。SEO 分数不代表加载或渲染性能评分。
- ego-browser 完成专题页和蓝关深链语义检查；其截图接口遇到导航超时，正式图像证据使用仓库要求的 Playwright。
