日期：2026-11-15。状态：本轮实现、构建与全量功能回归已通过；**P11 整体验收尚未通过**，性能预算、真机和正式域名仍有待办。下表逐项对应 PLAN 7–10，不将模拟测试写成真机结果。

## PLAN 7：性能预算

| 指标 | 目标 | 结果与证据 |
|---|---|---|
| 首屏核心 JS + CSS | ≤350 KiB gzip | **349.53 KiB gzip，通过**。含入口静态依赖、CSS 和动态 3D 引擎；见 [bundle.json](performance/P11/bundle.json) |
| 4G 中端安卓首次出图 | ≤3s | **未达标：3D 9.04s**；静态预览 FCP 0.92s。gzip 本地生产服务、1.6Mbps / 150ms / CPU×4，真机未测；见 [startup.json](performance/P11/startup.json) |
| 帧率 | 桌面60；指定手机≥50 | **未全项达标**：桌面41.63；iPhone 14视口58.55；Pixel 7视口57.03fps。固定高档、关闭自动降档，完整主页面拖动缩放；见 [summary.json](performance/P11/summary.json) |
| 生长准备 | 2048网格≤120ms | **未达标**。真实2048网格冷计算约4371ms，读回约245ms；预热命中约159ms。不能把运行时512/1024场冒充2048测量 |
| 手机内存 | ≤350MB | 桌面JS heap约124.9MiB，两手机视口分别约73.1/92.9MiB。GPU/原生与微信进程总内存需真机工具，**尚未测量** |
| Draw call | ≤250 | **通过**：桌面峰值125，iPhone视口53，Pixel视口63。保存全部采样 |

本机 GPU 为 Intel UHD Graphics / D3D11。iPhone 14、Pixel 7 都是该桌面 GPU 上的 Playwright 视口模拟。真实红米 K70 配置已填入 [真机模板](../DEVICE-TESTS.md)。FPS 使用全部 requestAnimationFrame 间隔，包含长帧；不删除超过250ms的停顿。脚本任何预算超限返回非零，不通过改阈值隐藏失败。

优化：稳定年份的疆域颜色用2048²纹理缓存，近景继续精细ID/SDF重建；边界同坐标高程计算去重且跳过不可见边界；高档限制玻璃模糊、省电关闭 backdrop-filter，折射限极致；二维码改按需加载；Service Worker 不预缓存所有实验室和vConsole；瓦片请求优先于非必要素材。首个低精度地形出现后再请求完整编年、搜索与地点目录，失败或8秒超时解除等待，实验室页面直接加载；同配置慢网模拟由首次17.02s降到7.46–9.04s，最终产物复测9.04s，仍未达到3s。帧率前轮Pixel视口为37.29fps，后轮57.03fps；单轮通过不代表稳定达标，真机模板要求连续3轮并记录最低值。

## PLAN 8：画质

- 省流量、2G、≤4GB内存或≤4核设备保守选省电，其余默认高，不凭核数猜测独显。
- 连续2秒帧耗时>22ms降一档，连续10秒<12ms升一档；修复长帧>250ms被忽略的问题。隐藏页面重置时钟，不计入掉帧。
- 更多菜单提供自动开关，手动选档同时关闭自动；三档参数继续控制地形、DPR、云、水面、粒子与标记。
- 自动化施加真实主线程负载，确认自动降档和手动保持，并保存录屏；这不是安卓真机验证。
- 现有光束/柔光采用直接着色器合成。PLAN表中的全屏Bloom/色彩分级仍没有独立后处理链；在性能目标未达成前未额外增加全屏渲染通道，这是未完成项。
