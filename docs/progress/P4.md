# P4 · 疆域渲染与可逆生长

## 完成项

1. GPU 在 Web Mercator 下生成桌面 4096²、手机 2048² 政权 ID 纹理；地形亮度与政权色混合，默认 40% 可调，未覆盖陆地暗 15%。保留都护府斜纹、邻国无填充与仅描边规则。
2. 纯 TS Felzenszwalb 有符号 EDT、半精度打包、变化政权集合、都城出生／收缩、Transferable Worker、96 MiB LRU 与相邻快照预计算。
3. GPU argmin 双场合成、金色前沿、水墨、消亡光尘；白色细内芯和彩色 1.5px 边界、8px 柔光，贴地形、生长时淡出、结束后朱砂虚线残影 3 秒。
4. setProgress / play / animateTo 接口，拖动可逆，900–1400ms 播放，快拖 120ms 交叉淡化；每项独立开关、三级画质预算、减少动态降级、WebGL 恢复。
5. /lab/morph 的 A/B 选择、滑块、正反播放；主程序时间订阅与验收控制台接入。准备完成前保留旧画面，过时请求不会覆盖最新选择。
6. 198 份轻量运行时政权文件与完整几何逐要素比较：5,100 政权要素、104 个孔洞，未丢失或改写边界；全量 CHGIS 与其他图层数据保留。实现细节见 [MORPH.md](../MORPH.md)。

生长时另有至多一次 ID 渲染目标合成；静止时不重复合成。手机实验室默认镜头拉远、目标南移，让疆域位于底部控制面板上方。

180 次 GPU 状态审计，共 94,371,840 个像素比较：新增缝隙 0、非法 ID 0、与 CPU oracle 不一致 0。每对快照的 t=0/.25/.5/.75/1 逐像素验证；A/B 反转的 .5 状态哈希完全一致。审计验证的是生成场分辨率，不把它声称为全部 4096² 像素的读回验证。

首次截图复核发现共用都城导致等距区域大块金光，已限制前沿为空间变化的窄带。改为直接数组遍历后，距离场准备明显缩短。GPU 合成只处理变化包围矩形；scissor 使用 RT 物理像素，不受手机 DPR 缩放影响。

## 偏差、未完成项与已知问题

1. 静态 ID 为要求的 4096²／2048²；距离场为桌面 1024²、手机 512²，以控制内存和逐帧开销。未变化区域和端点保留完整 ID，变化区域的小岛与细边界精度受距离场限制；局部高倍缩放仍可见栅格边沿。
2. 上游没有都城坐标的 6 个本轮涉及政权使用明确标记的区域质心：`unprofiled:qin:燕`、`unprofiled:qin:赵 · 代`、`unprofiled:qin:齐`、`unprofiled:xijin:晋`、`unprofiled:tang:中天竺（王玄策破敌）`、`unprofiled:roc:外蒙古（自治/苏控）`。没有杜撰坐标；原始资料保留待人工审校。记录含候选都城的来源不确定性，动画不应视为历史行军路径。
3. 边界柔光是屏幕空间解析包络，未引入全屏 Bloom；光尘按预计算前沿种子在 GPU 上求生命期。目录使用 engine/morph 集中本轮管线，避免跨多个特效目录分散生命周期。
4. 帧率如实列出：部分桌面录屏样本低于 50fps，不能声称每个案例均达到 50fps；手机模拟接近 60fps。尚无真机 GPU、网络冷启动和完整 GPU 内存峰值验收。
5. B12 大跨度穿云、政权名称避让、动态朝代面板属于后续阶段。主地图疆域与年份已联动，章节目卡仍沿用 P1 示例，不能把该卡片当作任意年份的实际史料。
6. 本轮未推送、未部署或改动 DNS。P0–P3 既有验收素材未覆盖，本轮回归素材放 P4/regression。
