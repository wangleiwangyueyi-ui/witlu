# P5 · 连续时间与历史长河

## 完成项

- `store/time`：无公元 0 年的连续索引，0.5/1/2/4×播放，跨章节自动减速，终点暂停；上/下一年、Shift 十年、左右键与空格；年份和汉字年号输入、有效区间检查、重名选择。
- Canvas 历史长河：完整政权 key、阶段面积比例、注册表颜色、分流与汇合、流动光点、全部事件光点和点击定位；朱砂玻璃印章、滚动数字年份。
- 惯性、慢速吸附、随拖动方向加速的水流；双指缩放、缩放按钮、双击复原；Android 12ms 边界震动及独立开关。
- 主纪年与所有有效并立纪年的君主/年号、当前章节、阶段概述、面包屑及附近大事。手机收起时显示 56px 紧凑长河，展开后显示 100px 长河。
- 拖动 `setProgress`，播放和跳转 `play` / `animateTo`；大于 300 年的 B12 镜头拔高、穿云、回落；三级画质和减少动态降级；验收控制台独立开关。
- `/lab/timeline` 与 `/lab/time-flight` 独立演示。实现与数据边界见 [TIME.md](../TIME.md)。

## 自动验收

`pnpm verify` 包含 typecheck、eslint/stylelint、纯核/引擎分层、Vitest、上游计数、地形/海洋/疆域校验和 Playwright。

- Vitest：111 项通过，其中时间换算与年号/河流模型 42 项。
- Playwright：58 项通过、68 项按视口或专门录制命令跳过；浏览器使用单 worker，避免共享 GPU 上同时录屏/恢复 WebGL 争用；冷启动页面总超时为 90 秒（原 30 秒在本机首次 Vite 转译时超时），不改变 FPS 或功能断言；未降低任何断言或上游计数；[完整日志](performance/P5/verify.log)。
- `pnpm test:timeline`：3 项通过，三种视口顺序录制，包含双向地图拖动、跨 300 年跳转、四个分裂时期拖动和独立穿云实验页。
- `pnpm build`：完整资产、数据、瓦片、类型和 Vite 构建通过；[构建日志](performance/P5/build.log)。Three.js 引擎块约 547kB（gzip 143kB），保留 Vite 大于 500kB 的提醒。
- 手机所有新增按钮、输入框、倍速选择器、缩放按钮和河流热区均至少 44×44 CSS px；事件使用 44×44px 拾取邻域。实际尺寸清单：[iPhone](performance/P5/iPhone-14-targets.json)、[Pixel](performance/P5/Pixel-7-targets.json)。
- 双指缩放通过 CDP 触摸事件验证；Android 震动通过调用探针验证开关及 12ms 参数，不冒充物理震感验收。
- 修复本轮发现的桌面时间坞遮挡复位按钮、双指缩放误改年份、小数年份逐年步进及节流丢失末次拖动位置问题。旧 P0–P4 证据保留，新回归证据写入 P5/regression。

## 偏差、未完成项和已知问题

1. 河流在阶段边界前最多 6 年（且不超过阶段长度的 20%）做示意分合；引擎按 PLAN 6.5 原始快照插值。这样统一时代不会因两个快照相隔上百年而提前呈现分裂，不改变面积原值和边界数据。
2. 复用 P3 自托管云纹理实现 B12 的屏幕云层通道和真实相机拔高/回落，未新增体积云。关闭 B12 或减少动态时保留年份定位功能。
3. 上游无某政权的区域年号时不编造君主/纪年。`贞观三年`存在唐/西夏歧义；可选结果或输入完整朝代前缀，不默认猜唐。
4. 密集事件使用最近点拾取；所有事件均绘制，当前附近文字列表展示六条大事。更完整的事件检索、卡片和 F05 语音解说按 `CODEX_PROMPTS.md` 后续阶段实现。
5. 三视口录屏全程尚不能保证稳定 50fps，跨快照 GPU 准备有停顿；未将这项记为“≥50fps 已通过”。手机模拟结果不代表真实手机发热、续航或震动效果。
6. 新 UI 标签与历史数据以简体中文为主，保留现有繁体/英文框架及君主英文名；新标签的完整翻译尚未补齐。
