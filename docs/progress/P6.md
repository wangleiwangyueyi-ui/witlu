- 章节标题使用 Make Me a Hanzi 固定提交 `bddc96d41bef78427ed0e034e9f7e31d71fd1b92` 的真实轮廓与中线逐笔绘制，然后朱砂印章落下、概述淡入。只打包 18 章简繁标题用到的 33 个字，JSON 71,166 bytes；保留 Arphic Public License、COPYING、来源摘要和修改说明。省电档缩短落笔时间；关闭开篇或减少动态时直接显示。
- 章节面板：18 章起止年、都城、概述、阶段 overview、全部章节大事、免责声明和原始致谢。历史位置与所有大事可跳转。
- 此刻天下和并行事件轨道直接读取政权注册表、主纪年及区域纪年；桌面最多四列并分页，手机分段控件与横滑卡片双向同步。同年事件在各自轨道同时高亮。
- B14 同期共鸣：去重后的全部同年地点同时泛起金色光圈、连通光丝，1.8 秒后结束；省电档关闭光丝，减少动态或独立开关关闭时停用。镜头按面板之外的地图安全区域取景。文字留在 Web 层，引擎只输出投影坐标。
- F11 图例：悬停 / 键盘聚焦突出政权，点击聚焦候选都城；F12 档案：中英文政权简介、都城、存续年、上游君主介绍及按纪年排序的继位列表，支持键盘关闭和焦点归还。
- N5 导览：覆盖全部 18 章、198 个阶段、526 条 milestone 大事（共 742 个讲述站点），章节 → 阶段 → 事件顺序讲述，按都城或事件编排镜头，五秒一站，可暂停、继续、前后跳章、结束。手动改变时间或页面隐藏时暂停。
- `/lab/chapters`：指定年份预设与开篇、同期共鸣独立开关；主界面 `?debug=1` 的开篇组已接入。
- P5 翻译：年份输入及错误、倍速、河流提示、缩放、支流、面包屑、主纪年、效果开关、实验页等均有简体 / 繁体 / 英文词条；上游已提供的英文政权、君主、章节与大事译文一并复用。
- L1：提高政权颜色曝光，继续使用地形晕渲亮度调制及默认 40% 填充；静止的连续年份沿当前解析出的归属边缘补同色亮线及柔光，运动中淡出，避免两张源快照的双重边界。主界面调整相机与底部留白，增加 Web 政权 / 都城标注。
- 拖动优化：三张高分辨率政权 ID 纹理 LRU 复用，按住拖动与惯性阶段跨快照使用不读回、不启动 SDF Worker 的交叉预览；松手且速度归零后 250ms 细化。相邻几何提前加载，空闲时预计算相邻距离场；保护正在准备和读回的纹理，正确清理 WebGL 恢复后的缓存。

## 验收与性能

`pnpm verify` 已完整通过：typecheck、eslint/stylelint、分层规则、119 项 Vitest、全部上游计数、9,970 张地形瓦片、海洋资源与疆域几何校验；Playwright 65 项通过、73 项按设备或独立录制命令跳过，用时 7.1 分钟。未降低计数或功能断言。[完整日志](performance/P6/verify.log)。

新增 GPU 审计在松手后检查 SDF 恢复，空洞、非法 ID、GPU/CPU 归属差异均为 0。两类热更新环境中的测试失败在全新 Vite 实例下已消除；手机测试先展开抽屉再检查隐藏控件。最终三视口录屏 3 项通过（3.0 分钟），明确断言 220–240 与 210–285 时间窗口；[录屏日志](performance/P6/recording.log)。`pnpm build` 通过，包含完整 `pnpm data`、资产、瓦片断点复用、typecheck 和 Vite 生产构建；[构建日志](performance/P6/build.log)。引擎块 556.85 kB（gzip 145.35 kB），保留 Vite 的 >500 kB 提示。

性能原始样本保存在 [performance/P6](performance/P6/)，开发中录制在 `before-drag-guard/`；这些轮次使用长时间热更新的服务器，没有窗口端点断言，仅保留供诊断，不作为严格性能提升证据。`matched-P5` 表示与 P5 相同的 220–240 年窗口；本轮新增章节面板和导览镜头，不能作为相同渲染负载的严格 P5 对照。跨快照窗口为 210–285 年。最终录制在全新 Vite 实例上验证窗口端点，所有轮次使用同一 Windows 桌面 Chromium / D3D11 GPU 上顺序录制，手机为视口模拟，不是实体设备。帧率保留冷加载 / 卡顿样本，不删除零值；进程录屏和系统负载会影响结果。

## 与 PLAN 的偏差和已知限制

- 桌面的四列事件轨道放在地图下缘、时间坞上方，右侧仍为 380px 章节面板。原因是四列长事件文本挤在 380px 面板内不可读；面板保留此刻天下与完整章节内容。地图已为两者留白。
- 君主世系使用上游可核实的君主介绍和有日期的纪年继承顺序。没有可靠亲子关系的政权不绘制虚构家族树；无纪年记录的政权明确提示。
- 上游未提供英文的阶段长文仍展示并标注“Original text”，少量无英文政权档案 / 地名保留原始史料；控件与提示词条已完整翻译。繁体使用上游字表转换，保留原始专名；繁体年号输入会转换到上游简体索引，例如「唐貞觀三年」可解析为 629 年。
- 事件归属沿用构建期的 `regime` / `lane`，不在 UI 猜测改写史料。例如 230 年航海到夷洲的事件按地点归属到夷洲，未塞入孙吴轨道；仍完整出现在章节大事列表和同期地点中。
- 地图标注为本阶段的政权 / 都城简版，完整 F38 地名避让属于后续地图标注阶段。
- 书法源数据独立采用 Arphic Public License，不误标为 GPL；站点代码继续 GPL-3.0。CHGIS 衍生数据未提交，上游文件与历史边界未修改。
- 桌面录屏仍有低于 50 fps 的区间，不能宣称稳定 50 fps；本阶段降低了重复准备负担，但高分辨率栅格化、全屏玻璃与录屏仍有成本。
