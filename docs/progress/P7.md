# P7 · 天象、音效与事件编排

验收日期：2026-11-13—2026-11-14。实现、三视口媒体与性能采样已完成；pnpm build 与 pnpm verify 均通过。微信真机验证和跨疆域准备长帧仍有下述限制。

## 完成内容

- 纯 TypeScript WeatherDirector 根据 moods.json 驱动悲恸、肃穆、征战、火攻、盛世、远行、诗意、天灾预设；1.2 秒渐入，普通事件到第 6 秒开始恢复，恢复 1.2 秒。每 10 秒最多触发一次；近现代惨案强制肃穆。4 倍速和减少动态效果只保留天色变化。
- GPU 实例化雨、雪、花瓣、光尘、火星、烟尘；雨量极致 30,000 / 高 8,000 / 省电 2,000。海面雨圈、程序化分叉闪电、150ms 全局补光与云内闪光、云隙光束、沿河洪水、赤壁火光与倒影、最多两次轻震均接入独立开关和画质预算。
- 秦灭六国逐个推进上游快照，魏段水淹大梁，统一后晨光、光束、书法与印章、沿上游秦长城走廊升起的三维城墙；靖康编排包含北来云雨、汴梁闪电、北宋到南宋生长、临安暖光和雨歇肃穆卡片。
- 主程序连续播放、拖动与跳转接入天气；修复分数年份在 4 倍速下持续重置延时、导致不能触发事件的问题。叙事锁避免普通时间订阅与演出抢占疆域和镜头。
- 雨、雷、风、海浪与古琴共用混音和总静音；默认无声，点击音乐按钮解锁，雷声延迟 0.8 秒，海浪音量依海岸距离变化。隐藏页面暂停声音；微信桥仅在已有用户声音同意后恢复。
- 四个原创程序合成 WAV 使用 CC0、自托管；生成脚本纳入 data/assets，来源、SHA-256 和许可随素材输出，[NOTICE](../../NOTICE.md) 已登记。没有引入第三方录音。
- 新增实验室 /lab/weather；主页面 /?debug=1 的“触发天象”提供六个指定场景、预设和独立开关。控件含简体、繁体、英文。

## 帧率与长帧

每格为 **平均 FPS / 最长帧 ms**。统计来自演出 active 期间的原始 requestAnimationFrame 间隔，包含超过 250ms 的长帧，不使用控制台排除长帧后的滚动 FPS。原始帧、引擎状态、叙事节点和错误列表见 [performance/P7](performance/P7)。录屏和自动化本身会影响测量。

## 实现选择、偏差与已知限制

- **未达到全场景 50fps**：桌面秦、靖康仍受疆域标签光栅化、SDF 准备和 GPU 上传影响。已经加入特效着色器预热、初始镜头/瓦片稳定等待、演出期间暂停后台 SDF 预计算、河道距离计算限定事件附近区域；仍有最高约 967ms 的长帧。P7 的记录要求已完成，不能据此宣称此前所有场景的 ≥50fps 目标均已满足。
- 示例表中的节点使用叙事时钟。SDF 未就绪时暂停叙事，保证六国顺序与疆域一致，实际墙钟时间会超过 PLAN 的秒数；天气运动使用独立视觉时钟，异步等待期间继续移动，但阻塞的 GPU 工作仍会卡顿。开始演出前最多等待 15 秒准备。JSON 中 beats.elapsedMs 是相对首个被测试观察到的事件时间，不是 Director 的理论节点时间。
- 盛世天空使用 PLAN 1.2 已有金色 token，未引入 6.7 另列的额外金色色值，以遵守 AGENTS 的严格色板要求。悲恸使用深蓝冷色，没有中性灰。
- 光束采用云隙遮罩的径向多次采样并直接合成，省去全场景后处理渲染目标；极致/高/省电为 16/8/0 次采样。火光、洪水和长城均为示意性演出，不是物理灾害模拟。
- 秦长城沿上游 wall_qin 数据挤出；为全国尺度可见采用示意宽高。统一后升起仅表示后续历史进程，不表示前 221 年已建成全部秦长城。未更改上游历史边界与走廊。
- 环境音为原创程序合成，非自然环境实录。微信用户手势和桥恢复路径已实现，但尚未在微信真机验证，也未做实体手机性能验收。
- moods.json 仍为关键词分类；人工历史情绪审校参见 [moods-review.md](moods-review.md)。运行时再对近现代惨案强制肃穆。
- 生产构建保留引擎 chunk 超过 500KB 的体积提示（约 574KB、gzip 151KB），构建成功。上游许可、CHGIS 致谢和免责声明保留；CHGIS 派生数据仍仅构建时生成。
