# P8 · 玻璃标记、历史走廊与地点溯源

验收日期：2026-11-14。实现、三视口截图与录屏已完成；生产构建与全量验证通过。性能和视觉分辨率限制见下文。

## 实现

- 六种程序化、实例化标记：都城印章、汉阙、交叉双戟、卷轴、玻璃珠、灯笼。几何属性总计 55,680 字节，低于 300KB；无需下载 glTF。极致与高画质使用物理透射玻璃，省电档使用边缘反光着色器；出现时弹簧放大、光圈扩散，减少动态效果时静态显示。
- 长城沿上游路径升起并依次点亮，运河五秒注水，丝路光点往返，1405–1433 郑和船队与白色航迹（其他海上丝路只显示流线），黄河旧道淡出/新道推进，迁都弧形光带与新都印章、行迹诗句三秒竖排浮现。省电关闭移动实例，减少动态效果关闭运动和航迹；每种效果有独立开关。实验室为 /lab/places，随后接入主地图。
- 地名在 Worker 中完成投影、排序和碰撞检测，避让章节面板、轨道、时间轴、地点卡和政权名。React 只创建标签节点；位置由引擎订阅更新，不以每帧 setState 驱动。手机标签热区至少 44px。地名标签上的拖动、滚轮和双指手势由同一相机输入处理，轻点仍打开地点卡；指北针纳入避让并置于标签上方。
- 点地溯源卡读取全部快照，按 18 章分组，列出同一地点各阶段政区变化、都城徽章、定点大事、史事纪要、名城题记；事件可跳转年份。支持长安、应天府、蓝关、函谷关等深链与地点搜索、多站路线。
- 郡州府/一级政区悬停、今属省份、现代省界、古今透视镜（鼠标随动和触控拖动）、河流湖泽与古海岸线、地图气泡及双击开卡。透视镜内双击使用与地图相同的经纬度拾取逻辑。
- 疆域纹理按离散 ID 查色后进行亚像素混合，过渡时未变化区域保留 4096² / 手机 2048² 原始纹理，变化边缘直接插值相邻政权的连续 SDF，避免全部退化到 SDF 工作分辨率。盛世光束去掉高频角度条纹，使用低频云噪声与径向衰减。

本轮固定高画质测量范围为 22.9–56.3fps，仍未达到全场景 50fps。物理透射、地形绘制与切换期几何准备仍有开销；不能据此宣称此前阶段的 50fps 目标已完成。

性能统计采用整个交互采样窗口的原始 requestAnimationFrame 间隔，包含准备长帧；不以控制台过滤长帧后的 FPS 代替。固定高画质并关闭自动降档。手机为 Windows Chromium / D3D11 的设备模拟，不能代替实体手机测试。原始帧、引擎样本和错误列表位于 [performance/P8](performance/P8)。

- PLAN 1.4 当前版本没有标记表，六种造型按本阶段任务实现。按用户允许采用程序化几何；环境反光由程序生成 PMREM，未额外下载 HDR。省电档关闭物理透射，控制移动端开销。
- 长城采用沿路径贴地的三维墙带，船、驼队和迁都弧线按全国尺度夸张，表达历史走廊，不是建筑复原或实测航迹。船队高度不低于海平面，避免沿海底潜行。
- 当前年份仅显示当时城池、名关、事件和行迹；无年代信息的完整 gazetteer 保留在搜索中，防止秦代地图默认出现元代上都等名称。
- 地点查询为示意性空间匹配：事件半径 40km、题记半径 45km、都城半径 35km，长安与咸阳等近邻会关联；卡片显示的并非精确城市行政沿革。上游未记录某地的时期明确为空，不补造历史。
- 湖泽面与走廊顶点在重建时采样地形，随后更精细瓦片到达时可能轻微浮贴。大范围带状地物与 SDF 生长中的变化区域仍有工作分辨率限制。
- P8 新地点卡已有英文主标题与主要操作；部分地理说明、图层特效标签仍保留中文，后续全站国际化审校需统一处理。

- pnpm test:places：29 passed / 4 skipped / 0 failed，约 7.5 分钟。4 个跳过是桌面专属深链及悬停检查在两种手机视口上的重复项。21 段录屏、34 张截图均已生成，录屏样本错误列表为空。
