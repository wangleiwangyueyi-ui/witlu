# P9 · 搜索、人物行迹、史局、小试与声音

验收日期：2026-11-14。实现、三视口截图与录屏、63 条 README 示例深链验收已完成，生产构建与全量验证通过。性能限制如实列于下文。

## 实现

- 万能搜索：人物姓名、别称与拼音 key；地点及英文转写；上游事件拼音索引；公元／公元前年份、年号纪年；长安、赤壁、贞观、霍去病快捷入口；轮换示例；`/`、Ctrl/Cmd+K、Esc、上下键与 Enter。多义年号列出可选结果，繁体年号先规范化再解析。
- 点人溯事直接使用上游 7 条精编行迹的全部 76 站；其余人物从人物 token、人物标签、定点大事及大事数据收集。支持最多三人比较，按年排序；同年且相距小于 20km 的站点合并为「同途」，明确显示无共同站点的状态。
- 站点为实例化玻璃灯笼，沿用高／极致物理透射、省电仿玻璃。每个人／阵营使用 PLAN 色板，当前路段为朱砂；金色流星弧线 B13 有独立开关，省电和减少动态效果关闭流星。完整引文在面板阅读，地图只短暂显示短摘句，避免遮挡版图。`/lab/explore` 使用同一数据与渲染入口。
- 安史、靖康均保留上游 10 节点、章节标题、双方阵营、出处、途经点、分兵路线与同年内部先后顺序。上一站／下一站、方向键、Space 自动导览；`person`、`event`、`stop`、`autoplay` 可由深链恢复。
- 舆图寻址：10 道不重复题，默认难度 4／4／2；深链所选王朝优先首题。隐藏地名、政权名和章节提示；点地图落针，针旁确认；球面距离按上游 80／200／380／600km 阈值计 100／80／55／25／0 分，绘制地形投影同心圈；累计成绩对应上游官阶。拖动和多指手势不提交答案，退出恢复地图标签。
- 五首自托管古琴可选择、调音量，保留统一静音、用户手势授权和微信音频桥处理。语音解说由用户主动开启，按此刻天下轨道顺序播报同年事件，再补读尚未归轨的事件；行迹模式播报当前站点。切换年份／站点取消旧队列；播报时降低琴声音量，浏览器不支持时显示说明。
- 四份上游 README 的不同深链集中在 [清单](performance/P9/readme-links.json)。增加 `zh-tw` 别名和 README 嵌入示例所需的坐标溯源、时间范围及紧凑嵌入布局；debug 模式仍保留完整工具栏用于检查。

## 数据、许可与边界

未修改 upstream、历史边界或计数阈值；没有新增外部音频、美术素材或服务。五首古琴继续使用 NOTICE.md 已登记的上游自托管素材。CHGIS 构建产物保持忽略，GPL-3.0、CHGIS 引用、上游致谢和示意性边界免责声明保留。

人物行迹的普通事件只显示上游实际记录，不推断未收录的旅行过程。20km 同途为展示用近邻归并，不表示精确的历史会面；行迹线与流星是示意路线。语音使用系统 SpeechSynthesis，优先本地同语言声音；设备可用声音决定听感与可用性，尚无实体微信或实体手机音频验收。Playwright 录屏不包含音轨，语音顺序通过可控语音队列测试，古琴文件及播放另行验证。

- `pnpm build` 完整构建通过；最后修正后再次执行网站生产构建通过。没有修改计数阈值，198 个快照、126 个人物条目、7 条行迹／76 个站点、5 首古琴均保持与固定上游一致。
- 三视口共 24 张截图、3 段录屏见下表；63 条深链逐条通过，含多站数量与多语言检查，结果写入 [readme-results.json](performance/P9/readme-results.json)。录屏三视口另行执行并通过；无录屏性能诊断也单独运行。
- 自动播放、逐站暂停、五首古琴实际切换与播放时间推进、用户授权前静音、语音队列顺序、省电材质与减少动态效果均有浏览器检查。没有实体手机或微信验收。

## 性能与测量边界

录屏期间点击下一站，采集其后 4.5 秒全部原始 rAF 间隔，包含疆域准备与长帧；下表是帧数除以窗口总时长，不使用引擎控制台过滤长帧后的数值。画质由现有自动调节管理，逐样本档位保存在 JSON。三种视口均运行于 Windows Chromium / Intel UHD Graphics / D3D11，手机为桌面设备模拟。

## 已知限制

- 系统语音在当前设备缺少相应声音时可能不可用，界面保留文字并显示错误，不承诺离线语音包。
- 原有章节和地点卡的部分英文内容仍有中文回退；本阶段新增控件提供简体／繁体／英文，人物与史局优先使用上游双语文本。
- 包体仍触发 Vite 大于 500KB 的 chunk 提醒；没有扩大报警阈值。
