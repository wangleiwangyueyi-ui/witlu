# R1 · v4 布局骨架

2026-11-18，分支 `codex/r1-layout`。基线为拉取后的 `main`（`dfa208f`）。布局参考了 `upstream/index.html` 和 `upstream/css/style.css`，上游子模块保持原样。

## 实现

- 52px顶栏：品牌、真实搜索输入、图层、雅乐、繁·EN、分享、唯一更多；古琴播放与五曲/语音合并在雅乐，导览移到更多。≤768px的工具收进更多。
- 桌面360px右栏与地图分区；全图/史志可切换，ResizeObserver同步实际画布尺寸。顶部紧凑纪年、年号、朝代范围、都城；下面此刻天下与本朝大事，沿用完整现有数据。所有并存政权纵向展示，不再截为横排四张。
- 52px通栏时间底栏贴底，唯一年份输入；移除大号年份、三维标签/标语、旧章节面板、地图下横排卡、独立版权行。免责声明与完整上游/CHGIS引用保留在关于及折叠图例中。
- 手机地图全屏，收起/半开/全开抽屉；96px时间轴固定顶部，史志内容独立滚动。默认收起，键盘和带速度判定的弹簧拖动保留。
- 地点卡覆盖右栏位置；镜头框选使用新画布尺寸；移除地图政权标签下重复都城文字，长名缩为燕（公孙氏）。
- PLAN第5节替换为v4布局。章节书法保留在实验页，原功能测试保留；旧入口测试迁移，新测全部政权卡数量及三档抽屉。

## 边界与未完成

右栏用现有数据呈现纪年、并存政权和大事，筛选与同期事件待 R3。二维地图、泳道与开场分别在 R2、R4、R5 实施。R1 的帧率检查采用既有冒烟用例，正式二维基准和真机结果待后续阶段。默认视图移除了重复的大号年份、章节面板和横排卡片。右栏保留纪年上下文，底栏提供可编辑年份。图例默认收起，展开后可聚焦政权和打开档案。
