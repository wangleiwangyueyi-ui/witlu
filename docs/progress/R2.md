# R2 · 正北二维历史地图

2026-11-19，分支 `codex/r2-map2d`。先从最新 `main` 拉取，R1 基线 `db9385d`。

默认使用 Three.js 正交相机，北向锁定，保留平移、双指或滚轮缩放、缩放上下限、键盘与经纬度拾取。`?terrain=1` 使用原三维相机、位移和玻璃标记。缩放仍沿用深链的距离约定。

默认取景从当前快照的主朝代与并立政权外环计算，包围盒的限幅边占地图区 73%。手机按宽度限制，给顶栏和折叠抽屉留出空间。时间轴操作不会自动重设默认视野，深链的 `center` 和 `zoom` 仍生效。

二维瓦片使用轻量平面与黛青晕渲，不请求 DEM；海色采用夜蓝，去掉底部渐隐。宽视野超出东亚详图范围时，用 11.4 kB 的 Natural Earth 海岸线铺底。河流细蓝线、现代省界淡虚线及郡州府均沿用图层开关。疆域用半透明独立配色、抗锯齿描边、内侧柔光和连续距离场。图例提供阶段圆点、政权色块聚焦、说明与致谢。比例尺随缩放和纬度变化，复位按钮在地图边角。政权名使用原地理锚点，其他地名经碰撞检查和缩放分级，保留都城双圈、州郡虚线和城池关隘小记号。

颜色构建检查了 198 个快照、1,292 条填色邻接，十色 CIELAB L* 60.9–68.6。普通视觉及三种全色盲模拟的最小 ΔE76 为 8.48，高于同一审计门槛 8.0。旧历史数据和图层计数均保持原样。[配色审计](performance/R2/color-audit.json) · [模拟图](performance/R2/vision-simulation.webp)

## 性能复测

测试用本机 Intel UHD / D3D11 Chromium，同一公元 230 年、高档固定画质，连续拖动与缩放。手机数据为桌面 GPU 的视口模拟。4G 测试使用相同网络条件（1.6 Mbps、150 ms 往返延迟、CPU ×4），从导航起计时，服务工作线程禁用。距离场使用与 P11 同组快照，使用真实 2048² 输入，分别记录 GPU 读回和 Worker 往返。交互时引擎使用分档控制的距离场。

| 指标 | P11 | R2 | 备注 |
|---|---:|---:|---|
| 桌面 1440×900 平均帧率 | 41.63 | 56.32 | 16.8 ms P95，峰值 33 次绘制 |
| iPhone 14 视口平均帧率 | 58.55 | 59.91 | 16.7 ms P95，峰值 19 次绘制 |
| Pixel 7 视口平均帧率 | 57.03 | 59.81 | 16.7 ms P95，峰值 19 次绘制 |
| GPU 读回 | 245.3 ms | 695.4 ms | 同一组三国快照 |
| Worker 冷计算（往返） | 4371.0 ms | 2910.6 ms | 同一组三国快照 |
| 2048 冷准备合计 | 4616.3 ms | 3606.0 ms | 未达 120 ms 总预算 |

桌面达到 R2 提纲的 55fps，仍低于原脚本的 60fps。两种手机视口达到 50fps。慢网模拟下，完整历史填色在 16.10 s 可用。2048 冷算虽有改善，离 120ms 仍有差距。`test:budgets`、`test:startup`、`test:growth-budget` 的失败退出码保留。[帧率](performance/R2/summary.json) · [首屏](performance/R2/startup.json) · [2048 准备](performance/R2/growth-2048.json)

生产首屏压缩体积为 349.97 KiB，发布文件数为 10,782，两项均达到原 P11 预算。[包体报告](performance/R2/bundle.json)
