# R5 · 首访开场

## 实现

- 星空中，地球从暗处浮现。白天使用 NASA Blue Marble 的 2004 年 7 月合成图，夜灯使用 Black Marble 2016。着色器按晨昏线显示灯光，海面可见掠射高光，地球边缘呈蓝色菲涅尔光晕。NOAA 的卫星云量帧在地表上方缓慢漂移。[原图与授权](../../NOTICE.md#r5-开场地球贴图)
- 1.5 秒后镜头从太平洋转向东亚并推近，金色轮廓标出中国区域。约 4 秒开始穿云。地球层过渡为和实况地图匹配的 Web Mercator 视野，再交叉淡出。落点取自实际地图相机和画布，交接期间保持原地图视野。
- 「两千四百年 · 一图观之」使用既有书法笔画数据按笔顺写出。穿云时缩向顶栏印章。普通开场编排为 5.6 秒，省电及 reduced-motion 使用同一地球的静止画面与 1.5 秒标题淡入。
- 首次自动播放沿用已有访问标记。跳过按钮和 Esc 随时可用，⋯ 菜单仍支持主动重播。缺少 WebGL 或素材加载失败时直接留在地图。
- 地图独立加载并先出帧，随后才请求开场代码、书法笔画和贴图。手机用 2048×1024，共 772,906 字节，桌面用 4096×2048，共 2,416,814 字节。生产构建使用仓库内的 WebP。可运行 `node scripts/build-opening.mjs` 从固定哈希校验的原图重新生成贴图。

## 时长和性能

同一台 Windows Chromium / D3D11 主机，固定「高」画质并同步录屏。手机数据为 Playwright 的设备视口模拟。用开场可见期间的 rAF 帧间隔计算平均 FPS 和 P95。时长从首个开场帧到开场层移除。三段录屏均通过 FFmpeg 黑帧区间检查，检测门槛为持续 80 ms、画面至少 97% 为近黑像素。

| 视口 | 开场时长 | 平均 FPS | P95 帧间隔 | 地图出帧到首个贴图请求 |
|---|---:|---:|---:|---:|
| 1440×900 | 5.37 秒 | 55.14 | 33.3 ms | 865 ms |
| iPhone 14 模拟 | 5.60 秒 | 59.64 | 16.7 ms | 662 ms |
| Pixel 7 模拟 | 5.60 秒 | 59.46 | 16.7 ms | 694 ms |

帧间隔、落点和网络请求的原始记录随报告附上。[桌面](performance/R5/desktop-opening.json) · [iPhone 14](performance/R5/iPhone-14-opening.json) · [Pixel 7](performance/R5/Pixel-7-opening.json)

## 验证

```powershell
$env:R5_ACCEPTANCE = '1'
pnpm verify --retries=1
Remove-Item Env:R5_ACCEPTANCE
pnpm build
pnpm verify:bundle
```

R5 的 12 项三视口专项通过，包括首访播放、载入与播放中跳过、刷新后抑制、减少动效、省电和精确取帧。自动化检查了地图先出帧、贴图分辨率、交接透明度、地图镜头保持一致，以及播放时长不超过 6 秒。

全量验证通过 159 项单测和 146 项浏览器测试，浏览器测试均一次通过。169 项按视口或旧录制模式跳过。上游 README 深链为 63/63。旧三维双指测试从无遮挡地图开始操作，保留了缩放、旋转和俯仰断言。

`pnpm build` 与 `pnpm verify:bundle` 均通过。首屏核心资源 gzip 后为 **347.06 KiB**，低于 350 KiB 门槛。发布文件共 10,797 个，文件数量及单文件大小预算均通过。[包体审计](performance/R5/bundle.json)
