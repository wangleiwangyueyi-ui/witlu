# R7 · v4 发布前回归

基于最新 `main` 的 `561cc7d`，在 `codex/r7-release` 完成。验收范围为本地开发和生产构建。

## 手机、微信兼容与海报

| 检查 | 结果 |
|---|---|

## 与 P11 性能对比

帧率使用 Intel UHD / D3D11 Chromium，在本地 gzip 生产服务打开 230 年，固定高档画质进行六轮平移缩放。手机数据来自模拟视口。4G 使用 1.6 Mbps、150 ms 延迟、CPU ×4，关闭缓存和服务工作线程。按同一脚本口径对比 P11 默认三维与 R7 默认二维。

## 回归与构建

`pnpm verify` 一次通过。159 项单测和 153 项浏览器测试通过，183 项按测试设计的视口或专项录制条件跳过。上游 README 深链 63/63，数据量对齐、地形、环境、疆域和天气核验及 MCP 均通过。R7 专项截图和录屏也单独执行通过。

复现截图与录屏时设置 `R7_ACCEPTANCE=1`，运行 `pnpm exec playwright test tests/release-v4.spec.ts`。图片中的手机 CSS 视口为 iPhone 14 的 390×664 和 Pixel 7 的 412×839。帧率脚本使用同一组设备预设。

`pnpm build` 和 `pnpm verify:bundle` 均通过，包含版本化瓦片与 PWA 缓存。组合后的首屏关键资源为 347.50 KiB。[R7 包体积预算](performance/R7/bundle.json)
